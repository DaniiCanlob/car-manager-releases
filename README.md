# Car Manager — versiones

Aquí se publican los instaladores de Car Manager. El código vive en un repositorio privado.

## Instalar en Windows

1. Abre [la última versión](https://github.com/DaniiCanlob/car-manager-releases/releases/latest) y descarga `Car-Manager-Setup-X.Y.Z.exe`.
2. Ejecútalo. Como el instalador no tiene firma de pago, Windows puede mostrar **"Windows protegió su PC"**: pulsa **Más información → Ejecutar de todas formas**.
3. Las siguientes versiones se instalan desde la propia app.

## Instalar en Android

1. Desde el celular, abre [la última versión](https://github.com/DaniiCanlob/car-manager-releases/releases/latest) y descarga `car-manager-X.Y.Z.apk`.
2. Ábrelo. Android pedirá permitir **instalar apps de esta fuente** para el navegador: actívalo y vuelve.
3. Las siguientes versiones se descargan desde la propia app (la primera vez pedirá permitir instalar desde Car Manager).

## Para la app

`version.json` es el índice que consultan las apps instaladas. Lo actualizan los workflows de publicación; no lo edites a mano.
